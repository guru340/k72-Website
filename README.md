# K72 Website

A modern, animation-rich landing page inspired by the **K72 Creative Agency** website, built to showcase advanced frontend development techniques, smooth interactions, and immersive user experiences. The project leverages **React**, **Vite**, **Tailwind CSS**, and **GSAP** to deliver high-performance animations, responsive layouts, and seamless page transitions. It serves as a demonstration of contemporary web design principles, component-based architecture, and motion-driven user interfaces. :contentReference[oaicite:0]{index=0}

---

## Overview

The project recreates a premium creative agency experience with visually engaging animations, elegant typography, and fluid scrolling effects. It emphasizes performance, responsiveness, and clean UI design while following modern frontend development practices. :contentReference[oaicite:1]{index=1}

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/guru340/k72-Website.git

cd k72-Website
```

---

### Install Dependencies

```bash
npm install
```

---

### Start the Development Server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## Production Build

```bash
npm run build
```

---

## Preview Production Build

```bash
npm run preview
```
