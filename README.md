
A modern and highly animated creative agency website inspired by the K72 design style. Built using React, GSAP, Tailwind CSS, and Vite, this project focuses on smooth user interactions, immersive animations, and premium UI/UX experiences.

Features
Smooth GSAP animations
Fullscreen animated navigation menu
Responsive design for all devices
Creative agency-inspired UI
Scroll-triggered animations
Modern typography and layouts
Reusable React components
Fast performance with Vite
Tailwind CSS styling system


Tech Stack
| Technology       | Purpose                  |
| ---------------- | ------------------------ |
| React.js         | Frontend Framework       |
| GSAP             | Advanced Animations      |
| Tailwind CSS     | Styling                  |
| React Router DOM | Routing                   |
| Vite             | Development & Build Tool |
